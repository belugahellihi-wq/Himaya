# 1.3.0-preview

- Новый знак Himaya, параллакс при прокрутке и ограниченная ширина карточек на планшетах.
- График за 7 и 30 дней и экспорт дневных сумм через меню Android.
- Отключена отладка APK. Проверяется структура EDNS-запросов, размер входящего DNS ограничен 4096 байтами, опции клиента не отправляются резолверу.

# 1.1.0-preview

Предварительная сборка для проверки на устройстве, не стабильный релиз.

- DNS over TLS и проверка ответа сервера вместо незашифрованного UDP.
- Ограниченные очереди запросов и корректная остановка активных соединений.
- Foreground VPN с уведомлением и кнопкой выключения.
- Светлый интерфейс с понятными статусами и настройками.
- Напоминания с аятами по желанию, с немедленным закрытием.
- Сбрасываемый счётчик DNS-запросов и честные пояснения о приватности.
- Unit-тесты обычных и повреждённых DNS-пакетов.
- Прямая сборка из исходников вместо распаковки вложенного архива.

Ограничения: DNS-only VPN, сторонний DoH/DoT и прямые IP могут обходить фильтр; TCP DNS локально не поддержан. Нужны испытания на Android-устройствах перед стабильным выпуском. Debug APK использует отдельный package ID `app.himaya.preview`.
