# Himaya · حماية

[Скачать Himaya 1.3 для Android](https://github.com/belugahellihi-wq/Himaya/releases/tag/v1.3.0) · [Все версии](https://github.com/belugahellihi-wq/Himaya/releases)

Спокойный помощник для осознанного использования интернета. Android-приложение фильтрует системные DNS-запросы через локальный VPN и Cloudflare Families, помогая ограничивать доступ к нежелательным доменам.

**Статус: 1.3.0-preview. Это предварительная версия, не гарантия полной защиты.**

## Интерфейс 1.3

- Тёмная изумрудная тема и авторский знак из двух переплетённых арок. При прокрутке знак и орбиты движутся с разной скоростью.
- Отдельные экраны главной, активности и настроек.
- Свой список до 100 доменов с блокировкой поддоменов. Поддерживаются IDN и вставка HTTP/HTTPS-ссылок.
- Дневные счётчики, график за 7 или 30 дней, таймер VPN-сеанса и отправка отчёта с дневными суммами через системное меню.
- 30-секундная анимированная пауза.
- Параллакс и переходы можно отключить в настройках. Учитывается системное отключение анимации.
- Все эффекты нарисованы средствами Android. WebView, JavaScript-моста и удалённых визуальных ресурсов нет.

## Возможности

- DNS over TLS с проверкой сертификата и имени сервера; без возврата к незашифрованному DNS при ошибке.
- Локальные правила доменов плюс фильтрация вредоносного и взрослого контента Cloudflare Families.
- Постоянное уведомление VPN с явной кнопкой выключения.
- Необязательные напоминания с аятами; разрешение «поверх окон» не нужно для работы фильтра.
- Локальный сбрасываемый счётчик запросов. Нет аккаунта, аналитики или журнала доменов.
- Проверка DNS-ответов, ограниченная очередь, закрытие сокетов и окон при остановке.

## Важно понимать

Himaya **не скрывает IP**, не туннелирует весь трафик и не анализирует содержимое страниц. Приложение направляет только UDP DNS к виртуальному адресу `10.111.222.2` через свой интерфейс; прочий трафик идёт напрямую. IPv6-трафик разрешён вне туннеля. TCP DNS и IP-фрагменты в этой версии не поддержаны. Ответы DNS ограничены 32 739 байтами.

Сторонний DoH/DoT, Private DNS, другой VPN, прямые IP-адреса и кэшированные ответы могут обходить фильтр. Контент внутри разрешённого домена (например, видеосервис или мессенджер) отдельно не фильтруется. Локальные правила по ключевым словам могут давать ложные блокировки. Счётчик отражает запросы, включая повторы и фоновую активность, а не посещения или действия человека.

Cloudflare Families блокирует как взрослый, так и вредоносный контент. Нулевая IP-запись не позволяет определить конкретную категорию; приложение не делает такого вывода о пользователе.

## Установка и настройки

Android 8.0+ (API 26). Сборка использует compile/target SDK 34; пригодность для публикации в магазине нужно проверить отдельно.

1. Установите проверенный APK и откройте Himaya.
2. Прочитайте пояснение и разрешите создание VPN. Другой VPN на этом профиле будет отключён.
3. Для ожидаемой работы отключите сторонний Private DNS и Secure DNS браузера. Это не делает защиту неуязвимой к обходу.
4. При желании разрешите уведомления и включите напоминания с отдельным разрешением показа поверх окон.
5. Для автозапуска можно включить «Постоянная VPN» в Android. **Не включайте «Блокировать соединения без VPN»**: режим не совместим с этим DNS-only VPN и может отключить интернет.

При недоступности TLS-сервера перехваченный запрос получает SERVFAIL. Это не системный kill switch: прочие соединения могут продолжаться. Проверка соединения выполняется при DNS-запросах; зелёный статус означает запущенный интерфейс, а не проверку каждого приложения.

## Конфиденциальность

Незаблокированные локально DNS-запросы передаются Cloudflare (`1.1.1.3` / `1.0.0.3`, TLS-имя `family.cloudflare-dns.com`, порт 853). Cloudflare получает домены и исходный публичный IP. Оператор сети видит соединение с Cloudflare; шифрование DNS не скрывает всю активность браузера. См. [политику DNS Cloudflare](https://developers.cloudflare.com/1.1.1.1/privacy/public-dns-resolver/).

На устройстве сохраняются настройки напоминаний и анимаций, пользовательский список доменов, общий счётчик и дневные суммы. Суммы старше 30 дней удаляются при очередной блокировке. Резервное копирование приложения отключено. Исходный код не содержит аналитики, рекламных SDK или загрузки истории.

## Сборка и проверки

JDK 17, Gradle 8.9, Android SDK 34 и Build Tools 34.0.0:

```sh
gradle testDebugUnitTest lintDebug assembleDebug --no-daemon
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Сборка Preview предназначена для проверки на устройстве. Android-отладка отключена. При смене тестового ключа Android не разрешит обновить старую Preview; её удаление сотрёт локальные настройки. Основную Himaya удалять не требуется. Debug-сборка имеет отдельный идентификатор `app.himaya.preview` и устанавливается рядом с исходной Himaya. Её настройки и счётчик отдельные; одновременно Android допускает только один активный VPN.

Workflow собирает и проверяет проект напрямую из исходников, без вложенного ZIP. Для стабильного релиза нужны постоянный закрытый ключ подписи, успешная проверка на реальных устройствах и подписанный release APK. Не храните ключ и пароли в репозитории.
